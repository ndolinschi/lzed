Anthropic's prompt engineering guide recommends these techniques:

- **Be clear and direct.** Give context, the goal and the exact output you want.
- **Use examples (multishot).** A few varied examples, often wrapped in `<example>` tags.
- **Let Claude think.** Ask for step-by-step reasoning before the answer.
- **Use XML tags.** Separate instructions, data and examples, for example with `<document>` and `<instructions>`.
- **Give Claude a role.** Use the `system` prompt.
