# Exercise Hint

Use this skill when the learner is stuck or asks for a hint on the current exercise.

## Instructions
1. Call the `get_hint` tool to reveal and retrieve the next hint for the active exercise.
2. Explain the conceptual principle behind the hint:
   - Clarify the syntax, method signature, or mental model the hint refers to.
   - Guide the learner on how to apply the hint to their code.
   - Remind them of the small XP cost of revealing hints, but reassure them that learning the concept is what matters most.
3. STRICT POLICY: Never reveal or write the complete solution code.
